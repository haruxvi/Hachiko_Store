# Teoría detrás de Hachiko

Esta sección explica **por qué** el sistema está hecho como está: qué concepto de bases de
datos, seguridad, estadística o derecho respalda cada decisión. Sirve para preparar la defensa
ante la comisión. El **cómo** (qué archivo hace qué) está en [`../codigo/`](../codigo/README.md).

| Documento | Para qué sirve |
|---|---|
| [Preguntas de la comisión](preguntas-de-la-comision.md) | Las preguntas más probables, con una respuesta corta, el concepto que la respalda y dónde mostrarlo en el código |

**Por escribir:** arquitectura, concurrencia y transacciones, seguridad, pagos en línea, datos
y ML, marco legal, y calidad y pruebas. Mientras tanto, la teoría de los modelos está en
[machine-learning.md](../machine-learning.md) y la de seguridad en
[seguridad-owasp.md](../seguridad-owasp.md).
